# RaceDay - Event Management System (PROG6212 POE Part 1)

[![Validate Documentation Files](https://github.com/Maluleke-Hope/prog6212-poe-RaceDay/actions/workflows/validate-docs.yml/badge.svg)](https://github.com/Maluleke-Hope/prog6212-poe-RaceDay/actions)

Overview
RaceDay is a full-stack web platform designed for South African road running, walking, and cycling events.

System Roles
- **Organiser**: Manages events, categories, and enters results.
- **Participant**: Registers for events, views race history, and tracks stats.
